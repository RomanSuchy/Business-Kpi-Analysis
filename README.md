# Business KPI Analysis (Python)

Dieses Projekt analysiert strukturierte Kundendaten und berechnet
zentrale Geschäftskennzahlen (KPIs) wie Umsatz, Durchschnittsbeitrag
und Schadenquote. Die Ergebnisse werden visualisiert und automatisiert
als Excel-Report exportiert.

## Technologien
- Python
- pandas
- matplotlib
- Excel

## Ziel
Demonstration der praktischen Anwendung von Datenanalyse:
Analyse von Geschäftsdaten und IT-gestützte Entscheidungsunterstützung.
